# Starter Sound Library

All sounds in this directory are CC0 licensed (public domain).
No attribution required. Safe for commercial use globally.

## Structure

```
/public/sounds/
  /start/
    ready-chime.mp3       — gentle bell, signals sequence starting
    lets-go.mp3           — warm, soft tone, encouraging
  /transition/
    moving-on.mp3         — soft swoosh, step advancing
    next-step.mp3         — gentle ascending tone
  /calm/
    breathe-in.mp3        — slow, soft tone for breathing in
    breathe-out.mp3       — slow, soft tone for breathing out
    calm-hum.mp3          — gentle ambient hum for calm sequences
  /celebration/
    well-done.mp3         — warm, positive chime
    great-job.mp3         — soft fanfare, not overwhelming
    stars.mp3             — gentle sparkle sound
  /pacing/
    tick-soft.mp3         — very quiet tick for timer steps
    pulse-gentle.mp3      — soft pulse beat for pacing
```

## Sound Principles (from design guardrails)

- Nothing sudden, sharp, or startling
- Nothing that loops by default
- Volume: moderate — never auto-blast
- Duration: 1-3 seconds max for cue sounds
- Celebration sounds: warm and positive, NOT triumphant game-show style
- Calm sounds: slow, low, simple
